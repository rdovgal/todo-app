# 📝 To-Do менеджер

Консольное приложение для управления списком задач на Python.

## Возможности
- Добавление, просмотр и удаление задач
- Сохранение задач в файл между запусками
- Защита от некорректного ввода

## Как запустить
python3 main.py

## Чему я научился
Функции, списки, циклы, обработка исключений (try/except), работа с файлами.
